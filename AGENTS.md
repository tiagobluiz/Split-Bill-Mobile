# Release announcements

When a new feature is being merged, ask the maintainer whether it should be included in the next What's New announcement. Prepare approved highlights for the intended release. Releases without relevant highlights do not need an announcement.

Bundle only the latest What's New announcement. When a release has approved highlights, replace the slide set and update its announcement version. When a release has no new announcement, keep the existing slides and their announcement version so users who skipped the earlier release can still see them.
