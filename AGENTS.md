# Release announcements

When a new feature is being merged, ask the maintainer whether it should be included in the next What's New announcement. Prepare approved highlights for the intended release. Releases without relevant highlights do not need an announcement.

Keep previous What's New announcements bundled with their original versions. Append a slide set for each release with approved highlights and keep the English and Portuguese copy in the translation catalogues. Releases without highlights need no entry. Users who skip updates see all unseen announcements through their installed version.
